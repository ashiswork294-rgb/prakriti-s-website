# Prakriti Sapkota — Personal Website

A simple, responsive personal introduction website built with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages.

## Files

- `index.html` — page content and sections
- `style.css` — layout, colors, responsive design, and image sizing
- `script.js` — click-to-view full-size gallery
- `images/` — all six supplied photographs
- `README.md` — this guide

## Preview locally

Open `index.html` in a web browser. The page uses relative file paths, so keep the `images` folder alongside the HTML, CSS, and JS files.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository (for example, `prakriti-website`).
2. Upload **all files and the `images` folder**, preserving the folder structure. Do not upload only `index.html`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.

## Photo display

The gallery thumbnails show each photo in its original aspect ratio instead of cropping it. Clicking a photo opens a larger view that fits the screen, so the full photo is visible.

## Privacy note

Because Prakriti is a minor, consider whether you want to publish her age, parents' names, school details, and photographs publicly. You can remove those details from `index.html` before publishing. Only publish with appropriate family permission.

## Customizing

- Change text in `index.html`.
- Adjust colors and layout in `style.css`.
- Replace images inside `images/`, keeping the same filenames or updating the matching paths in `index.html`.
